Control Center Merge

A private tool for one person. Last updated 30 October 2026.

Control Center Merge is a small script that runs on Dr. Yousef Alsayed's own computer. Every few minutes it reads short status notes he saves to one folder in his Google Drive and files them into his own Google Doc ("Control Center"). It is not offered to anyone else, and nobody else can sign in to it.

Privacy policy

Who uses it. Only the owner, Dr. Yousef Alsayed, using his own Google account.

What Google data it accesses. With the owner's permission it uses:

  • Google Drive: to list and read the note files in one Drive folder ("Control Center Inbox"), and to move each note to Drive's trash once it has been filed.
  • Google Docs: to read and edit one document, "Control Center — Yousef".

It does not read, change or delete any other files, emails, contacts or calendars.

How the data is used. Only to file the owner's notes into his own document. To decide which section a note belongs in, the text of the note and of the document is sent to Anthropic's Claude AI model, which returns a filing suggestion. The script itself makes every change in Google Drive and Docs; the AI model has no access to the Google account.

Storage. The Google sign-in token is stored only on the owner's computer, readable only by his user account. The script keeps a local log of what it filed. No data is kept on any server run by this tool.

Sharing. Data is not sold, used for advertising, or shared with anyone, apart from the text sent to Anthropic as described above, under Anthropic's own terms and privacy policy.

Google API Services User Data Policy. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Stopping access. The owner can remove the tool's access at any time at myaccount.google.com/permissions.
